# EduWealth AI 🚀
### "Turn Financial Knowledge into Financial Freedom"
**AI-Powered Financial Education & Wealth-Building Platform for College Students and Young Adults**

---

## 🌟 Concept & Mission

College students and young adults often struggle with financial anxiety, lack of practical money management education, predatory instant loan apps, and aggressive "get-rich-quick" scams. 

**EduWealth AI** bridges the gap between **academic education and real-world financial success** through an integrated 7-stage pipeline:

$$\text{Learn} \longrightarrow \text{Earn} \longrightarrow \text{Budget} \longrightarrow \text{Save} \longrightarrow \text{Invest} \longrightarrow \text{Protect} \longrightarrow \text{Build Wealth}$$

> [!IMPORTANT]
> **Educational & Simulation Platform**: EduWealth AI is designed strictly for financial education and virtual practice. It does **NOT** provide personalized real-money investment advice or execute real financial transactions. In compliance with safety standards, zero sensitive banking credentials (passwords, card numbers, OTPs, UPI PINs) are requested or stored.

## 💻 Tech Stack & Architecture

- **Frontend**: Single-Page Application (HTML5, Tailwind CSS via CDN, custom fintech design system in `css/styles.css`).
- **Icons & Visuals**: Lucide Icons CDN, SVG progress gauges, Canvas Confetti.
- **Data Visualizations**: Chart.js (Donut charts, Bar charts, Line charts, Multi-axis Radar charts).
- **State Management**: Reactive singleton store (`js/state.js`) with pub-sub subscribers and automatic `localStorage` persistence.
- **Server**: Zero-dependency Node.js HTTP server (`server.js`) with static routing and SPA fallback.

---

## 🚀 How to Run the Prototype

1. Open your terminal in the project directory (`c:\SIH`).
2. Start the local server:
   ```bash
   node server.js
   ```
3. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
4. You can also directly open `index.html` in any modern browser without any web server!
